# Workspace Structure

This repository keeps active Deadlock mod sources at root and stores
non-runtime artifacts in `_archive/`.

## Active Root Layout

- `/<mod_name>/panorama/...`
  - Primary Panorama source modules (JS/CSS/XML).
- `/<mod_name>_compiled/...`
  - Compiled output generated by `sr2compiler` or module-specific compilers.
  - Compiled folders remain adjacent to their source modules.
- `/abilities/`
  - Large VData files plus processing scripts.
- `/sr2compiler/`
  - Source 2 quick compiler wrapper and config.
- `/passive_items_mod/`
  - Standalone configurable mod and local compiler flow.
- `/.agents/`
  - Agent skills and supporting instructions.

## Source Module Conventions

- Do not rename or relocate active source mod folders unless a dedicated
  migration plan is approved.
- Keep source edits inside each module's `panorama/` tree (or module-specific
  script folders like `abilities/scripts`).
- Keep compiled outputs in existing `*_compiled` sibling folders.

## Archive Policy

- Store nonessential repo metadata under:
  - `/_archive/meta/`
- Store loose, non-runtime root artifacts under:
  - `/_archive/misc/`
- Keep archive items versioned unless explicitly purged.

## Cleanup Policy For Future Additions

- Keep at root:
  - Active mods, build tools, core docs, and required project configs.
- Move to `_archive/meta`:
  - Agent/session planning state, temporary process notes, tooling metadata not
    required by the build pipeline.
- Move to `_archive/misc`:
  - Ad hoc root files that do not affect build/runtime behavior.
- Remove (do not archive):
  - Local caches and transient machine artifacts (for example `.ruff_cache`,
    upload temp folders, or disposable scratch files).
