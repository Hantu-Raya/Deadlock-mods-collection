# Old Main Menu (pak04)

The Jul 2025 (build 5712) Deadlock main menu on the current client. Read `RESEARCH.md` first. It covers the sources, the removed engine hooks, how each piece is replaced, and the open live checks.

- Build: `powershell -ExecutionPolicy Bypass -File build_old_main_menu.ps1` (deploys to addons\pak04 and backs up a different installed pak04 to `addons_disabled`). Use `-Strict` to drop the post-Jul-2025 play modes and `-SkipDeploy` to only build.
- Validate: `node old_main_menu/scripts/validate-old-main-menu.js`. It checks against the installed client: panel classes and events in client.dll, localization tokens, images in pak01, includes, the script budget, and that movies are packed.
- `panorama/styles/dashboard.css`, `citadel_db_page_play.css` and `citadel_db_page_home.css` are generated by `tools/derive_from_5712.py` from GameTracking 5712 and current files. Change the patch list there, not the output.
- Old binaries are never committed. `assets.json` pins each one by crc/size (images) or sha1 (install movies), and the build extracts them from the sources listed there.
- Keep the dashboard script small: no new hero data tables and no polling faster than 1 s. Prefer engine widgets and current events. A hook that client.dll no longer has must not be referenced (the validator's `REMOVED` list).
- Conflicts: pak04 overrides `dashboard.xml`, `citadel_db_page_home.xml`, `citadel_db_page_training.xml` and the global `citadel_hero_card.css` / `citadel_hero_grid.css`, which restyle every hero grid, including the roster picker. Any other pak that overrides those files conflicts with it.
- The Heroes page (`citadel_db_page_heroes.*`, `citadel_hero_*.css`) is the forked pak04's. Its `restoremenu_*` dashboard attributes and `RestoreMenu_OpenHeroes` are a contract with `old_main_menu.js`.
