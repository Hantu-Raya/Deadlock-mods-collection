# KAIZ HUD KNOWLEDGE BASE

## OVERVIEW
Comprehensive HUD redesign focusing on health bars, ability icons, and cast bars.

## FILES
- **Health Colors**: `health_bar_color.js` implements custom coloring logic.
- **Styles**: Extensive CSS overrides in `panorama/styles/`.
  - `hud_health.css`: Player health bar styling.
  - `unit_status.css`: Minion/Enemy health bars.

## LOGIC
- **Health Coloring**: Interpolates colors based on HP %.
- **Status Icons**: Custom icons for stunned/silenced states.
