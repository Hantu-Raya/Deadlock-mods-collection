# Map: DLF observer HUD

## Destination

A spectator HUD for the DLF league on the observer's PC: broadcast banner with an ESC-menu editor, soul lead graph, pickup rings, ult counters and debuff icons on the top bar, in one pak01 plus three loose fonts. Behavior is in [SPEC.md](SPEC.md); the work was done in small user-driven steps, so this file records status and dates rather than a ticket tree.

## Notes

- Start with [AGENTS.md](AGENTS.md) for rules and commands, [CONTEXT.md](CONTEXT.md) for vocabulary and [SPEC.md](SPEC.md) for behavior. [design.md](design.md) holds the banner and card geometry and the build contracts. Read [ENGINE.md](ENGINE.md) for engine constraints, [docs/adr/](docs/adr/) for decisions and [LIVE-VERIFIED.md](LIVE-VERIFIED.md) before making live claims.
- Observer HUD (`observer_hud/`) is a separate pack that reuses DLF's debuff column design and `spectator-status.json`. Its docs: [observer_hud/MAP.md](../observer_hud/MAP.md).
