HOW TO USE THIS MOD CONFIGURATOR
==============================

1. Double-click "Configure Mod.html".
2. Adjust the slider to your preferred position.
3. Click "Save Settings" and save the "settings.json" file to this folder.
   (Overwrite the existing file if asked).
4. Double-click "Apply.bat" to compile and package the mod.
5. After completion, use `pak99_dir.vpk` in the repository root.
6. Then place the pak file in the addons.

TROUBLESHOOTING
---------------
- If "Apply.bat" fails, make sure Dota 2 is installed.
- Ensure "settings.json" is in the same folder as "Apply.bat".
