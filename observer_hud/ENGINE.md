# Observer HUD engine evidence

Evidence is scoped to the named build and observation. **Live** means seen in the game; **RE** means static binary inspection; **VM** means a synthetic validator check or an inherited assumption, not native verification. Consult [LIVE-VERIFIED.md](LIVE-VERIFIED.md) before claiming native acceptance. The stock layouts the validator boots in are pinned in [stock-pin.json](stock-pin.json) (GameTracking commit `0abfe676`).

Build labels: **6812** is the spike and v1 live runs (2026-10-22). **6813** is the objective-timer probe and later live checks (2026-10-22). "Not recorded" means the source doc does not name the client build.
