## CONVENTIONS
- **JS**: Use `IIFE` + `'use strict'`. No external modules.
- **CSS**: Use `wash-color` for dynamic tinting. `overflow: noclip` for overlays.
- **XML**: Use `hittest="false"` for overlays to prevent blocking clicks.
- **Perf**: Cache `FindChildTraverse`. Avoid regex. Use `Date.now()` over `Game.GetGameTime()` for UI animations.

## ANTI-PATTERNS (THIS PROJECT)
- **DO NOT** use `$.GetContextPanel()` inside loops (cache it).
- **DO NOT** create `new Array/Object` in render loops (GC pressure).
- **DO NOT** rely on `visible` property alone for menus (check `BHasClass` on root).

## PERFORMANCE OPTIMIZATION
### FindChildTraverse Caching
Cache UI references at boot. `FindChildTraverse` is expensive (O(N)).
```javascript
const UI = { root: null, label: null };
function boot() {
  UI.root = $.GetContextPanel();
  UI.label = UI.root.FindChildTraverse("MyLabel");
  if (!UI.label) $.Schedule(0.5, boot);
}
```

### Game Time Retrieval
Native `Game.GetGameTime()` can fail/return 0. Use UI clock fallback.
```javascript
function gTime() {
  try { return Game.GetGameTime() || 0; } catch { return uiClockTime(); }
}
```
